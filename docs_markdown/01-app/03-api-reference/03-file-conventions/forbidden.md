# forbidden.js

> **Documentación Oficial Next.js v16.3.7**  
> 🌐 **URL en vivo:** [https://nextjs.org/docs/app/api-reference/file-conventions/forbidden](https://nextjs.org/docs/app/api-reference/file-conventions/forbidden)  
> 📂 **Sección:** App > Api Reference > File Conventions  
> 📝 **Descripción:** *API reference for the forbidden.js special file.*  

---

The **forbidden** file is used to render UI when the [`forbidden`](/docs/app/api-reference/functions/forbidden) function is invoked during authentication. Along with allowing you to customize the UI, Next.js will return a `403` status code.

```tsx
// Archivo: app/forbidden.tsx switcher
import Link from 'next/link'

export default function Forbidden() {
  return (
    <div>
      <h2>Forbidden</h2>
      <p>You are not authorized to access this resource.</p>
      [Return Home](/)
    </div>
  )
}
```

## Reference

### Props

`forbidden.js` components do not accept any props.
